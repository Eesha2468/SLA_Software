# SLA Management System — Backend Server

## Tech Stack
- Node.js + Express
- PostgreSQL (pg)
- dotenv, cors

## Setup & Run

### 1. Install dependencies
```bash
cd server
npm install
```

### 2. Configure database (.env is already set)
```
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=Eesha@1122
DB_NAME=SLA_System
PORT=5000
```

### 3. Start the server
```bash
npm start
```
Server runs at: http://localhost:5000
